Política de privacidad

Physical Exercises · Última actualización: 26 de octubre de 2026

Esta política explica cómo se tratan los datos cuando utilizas Physical Exercises, una aplicación web para organizar ejercicios, planificaciones y progreso. La aplicación está diseñada para funcionar en tu dispositivo y no tiene un servidor propio que reciba tus datos.

Responsable y contacto

La responsable del proyecto es Raquel Soler Viveros. Para consultas sobre privacidad o para ejercer tus derechos, escribe a halura@hotmail.com.

Qué datos se tratan

  • Los datos que introduces en la aplicación: ejercicios, categorías, imágenes, planificaciones y progreso diario.
  • Si conectas Google, la dirección de correo de la cuenta seleccionada, para que puedas identificarla en la aplicación.
  • Si configuras la opción avanzada de GitHub, el nombre del repositorio y el token que proporcionas para acceder a él.

No introduzcas información que no quieras almacenar en tu dispositivo o, si activas la sincronización, en el servicio que elijas.

Dónde se guardan tus datos

Los datos de la aplicación se guardan en el almacenamiento de tu navegador y dispositivo. La aplicación utiliza SQLite en el navegador; si el navegador no permite el almacenamiento persistente, los datos pueden mantenerse solo mientras dure la sesión. Borrar los datos del sitio o del navegador puede eliminar la copia local.

La sincronización es opcional y solo se inicia cuando la solicitas. Si eliges Google, los datos de ejercicios y sus imágenes se guardan en el espacio privado de la aplicación en tu cuenta de Google. La aplicación solicita el permiso drive.appdata: no accede a tus documentos, otros ficheros ni a tu correo. El correo de la cuenta se guarda localmente para mostrar qué cuenta está conectada. El acceso se realiza directamente entre tu navegador y Google; la responsable no recibe una copia de esos datos.

Si eliges GitHub, los datos se guardan en el repositorio que indiques. El nombre del repositorio y el token que proporcionas se conservan en el almacenamiento local de tu navegador. Al sincronizar, tu navegador se comunica directamente con GitHub y envía el token a ese servicio para realizar la operación.

También puedes exportar una copia de seguridad a un fichero JSON e importarla en otro dispositivo. La exportación se descarga en el lugar que elijas; la aplicación no la envía a ningún servicio. Tú eres responsable de proteger el fichero y eliminarlo cuando ya no lo necesites.

Cómo se usan y comparten los datos

Los datos se utilizan únicamente para guardar, mostrar, exportar, importar y, cuando lo solicites, sincronizar la información de la aplicación. No se venden ni se utilizan para publicidad o elaboración de perfiles. La aplicación no incorpora un servicio propio de analítica.

Al utilizar Google, el acceso a sus datos se limita a proporcionar la sincronización que has solicitado y se rige también por la Política de datos de usuario de los servicios de API de Google , incluidos sus requisitos de uso limitado. Google y GitHub tratan los datos que reciben conforme a sus propias políticas de privacidad. La aplicación también carga fuentes e iconos alojados por Google Fonts; al solicitarlos, tu navegador puede transmitir a Google datos técnicos como la dirección IP y la información del navegador.

Conservación y eliminación

La copia local permanece en tu navegador hasta que la elimines o borres los datos del sitio. Las copias de Google o GitHub permanecen en la cuenta o repositorio correspondiente hasta que las elimines allí. Desconectar Google retira la conexión de la aplicación, pero no borra los datos guardados en Google. Olvidar la configuración de GitHub tampoco elimina el repositorio ni su contenido.

El token de acceso de Google solo se mantiene en memoria mientras se utiliza y no se guarda en el almacenamiento local. Puedes retirar el acceso desde tu cuenta de Google. El token de GitHub se conserva localmente hasta que olvides esa configuración o elimines los datos del sitio; también puedes revocarlo desde GitHub.

Tus derechos

Puedes solicitar acceso, rectificación o eliminación de los datos personales que te conciernan, así como ejercer los demás derechos reconocidos por la normativa de protección de datos, escribiendo a halura@hotmail.com. Como la responsable no recibe las copias que guardas en el navegador, Google o GitHub, su consulta o eliminación debe realizarse también desde el dispositivo, cuenta o repositorio que controles. Si consideras que tus derechos no han sido atendidos, puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

Cambios en esta política

Esta política puede actualizarse si cambia la aplicación o el tratamiento de los datos. La fecha de la última actualización aparece al principio de esta página.

## Jerarquía Visual y Diseño

- [ ] CHK001 Are the visual distinctions required for list items ("tarjeta o fila con espaciado y jerarquía tipográfica claros") specific enough to be implemented consistently, rather than left to individual interpretation? [Clarity, Spec §FR-002]
- [ ] CHK002 Is the typographic hierarchy referenced by FR-002/US1 tied to a concrete scale within spec.md itself, or does it only exist in a separate design-tokens contract with no back-reference from the spec? [Traceability, Spec §FR-002 ↔ Contract design-tokens]

- [ ] CHK009 Is the edge case for screens narrower than 360px tied to a measurable pass/fail condition (e.g., "no horizontal scroll, no overlapping elements"), or only a qualitative statement? [Measurability, Spec §Edge Cases]

## Accesibilidad (WCAG 2.1 AA)

- [ ] CHK010 Does spec.md enumerate the concrete WCAG 2.1 AA success criteria in scope (contrast, focus visibility, keyboard operability), or does FR-015 reference the standard without restating which specific guarantees apply to this feature? [Completeness, Spec §FR-015]
- [ ] CHK011 Is the requirement that operation confirmations be perceivable by assistive technology (e.g., announced without moving focus) stated in spec.md's functional requirements, or does it only appear in the accesibilidad contract without a corresponding FR? [Traceability, Spec §FR-008 ↔ Contract accesibilidad]
- [ ] CHK012 Are the numeric contrast thresholds (4.5:1 text, 3:1 large text/icons) present anywhere in spec.md, or only in the design-tokens contract with no FR/SC cross-reference? [Traceability, Gap]
- [ ] CHK013 Does "navegación por teclado en todos los controles" (Clarifications, FR-015) specify which non-standard interactive elements (e.g., category selection chips) must remain keyboard-operable, or is this left implicit? [Clarity, Spec §FR-015]
- [ ] CHK014 Are accessibility requirements addressed for the "próximamente" placeholder screens, or implicitly assumed as not applicable because they are non-interactive? [Gap, Spec §FR-013]

## Cobertura de Escenarios
